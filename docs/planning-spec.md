## 1. 기존 기획 분석 및 현재 구현 상태

### 1-1. 현재 구현 상태 (사용자 검증 기준)

> **판단 기준**: 사용자가 웹(localhost:8081)에서 직접 확인한 결과 기준.
> 코드가 존재하더라도 실제 동작이 확인되지 않은 화면은 ❌ 미검증으로 표기.
> 클릭/탭 인터랙션이 전반적으로 작동하지 않아, 페이지 뎁스가 있는 모든 화면은 미검증.

| 영역 | 화면 | 상태 | 비고 |
|------|------|------|------|
| Auth | Splash | ❌ 미검증 | 코드 존재하나 실제 동작 확인 안 됨 |
| Auth | Walkthrough (3슬라이드) | ❌ 미검증 | 코드 존재하나 실제 동작 확인 안 됨 |
| Auth | Login | ❌ 미검증 | 소셜 로그인 미구현, 이메일 로그인 미검증 |
| Auth | Signup | ❌ 미검증 | 가입 플로우 실제 동작 확인 안 됨 |
| Auth | Preference | ❌ 미구현 | UI 스텁만 존재, 카테고리 선택 미구현 |
| HOME | 루틴 스토어 메인 | ⚠️ UI만 | 화면 렌더링은 되나 클릭/탭 인터랙션 미작동 |
| HOME | 루틴 상세 (`/routine/[id]`) | ❌ 미검증 | 카드 클릭이 안 되어 진입 불가 |
| HOME | 결제 (`/purchase/[id]`) | ❌ 미검증 | 상세 페이지 진입 불가로 결제도 불가 |
| BOARD | 투두 보드 | ⚠️ UI만 | 화면 렌더링은 되나 인터랙션 미검증 |
| POST | 커뮤니티 피드 | ⚠️ UI만 | 화면 렌더링은 되나 인터랙션 미검증 |
| MY | 프로필 메인 | ❌ 미작동 | 스피너만 표시, 프로필 정보 로드 안 됨 |
| MY | 내 루틴 | ❌ 미검증 | MY 메인 진입 불가로 확인 불가 |
| MY | 설정 | ❌ 미검증 | MY 메인 진입 불가로 확인 불가 |

### 1-2. 스텁(껍데기)만 있는 화면

| 화면 | 현재 상태 | 보강 필요 사항 |
|------|-----------|---------------|
| Preference | 빈 화면 | 카테고리 칩 선택 UI + 저장 로직 |
| REWARD 탭 | 빈 화면 | 전체 신규 구현 (MVP 이후) |
| 프로필 편집 | 스텁 | 닉네임/소개/사진 변경 폼 |
| 팔로워/팔로잉 | 스텁 | 리스트 + 팔로우 토글 |
| 구매 내역 | 스텁 | 구매 리스트 + 상태 표시 |
| QR 센터 | 스텁 | QR 생성/스캔 (MVP 이후) |
| 알림 설정 | 스텁 | 토글 3개 (일정/커뮤니티/마케팅) |

### 1-3. 현재 Gap 분석 (기존 기획 vs 구현)

> **중요**: 아래 Gap은 개별 기능이 아닌 **애플리케이션 전체**에 해당하는 문제임.
> 현재 앱은 UI 렌더링은 일부 되지만, 클릭/탭 인터랙션이 전반적으로 작동하지 않아 사실상 어떤 플로우도 완결되지 않음.

**전체 앱 레벨 Gap:**
1. **클릭/탭 인터랙션 전체 미작동**: 모든 버튼, 카드, 링크의 터치/클릭 이벤트가 동작하지 않아 페이지 이동 불가
2. **Auth 플로우 전체 미작동**: Splash → Walkthrough → Login → Signup → Preference 전체 흐름이 검증되지 않음
3. **소셜 로그인 미구현**: 카카오/애플/구글 OAuth가 실제로 구현된 것이 아님 (데모 코드도 미검증)
4. **MY 페이지 데이터 로드 실패**: 스피너만 무한 표시, 프로필 정보가 전혀 로드되지 않음
5. **페이지 뎁스 네비게이션 전체 불가**: 루틴 상세, 결제, MY 하위 화면 등 depth가 있는 모든 화면 진입 불가
6. **결제 후 → BOARD 연결 끊김**: 결제 완료 후 "일정 설정하기" 없이 HOME으로만 돌아감
7. **Board 요일 선택이 투두 필터링과 미연결**: UI만 존재, 실제 데이터 필터 안 됨
8. **구매한 루틴 → Board 자동 반영 안 됨**: purchaseStore와 boardStore 미연결
9. **Preference 화면이 비어있음**: 온보딩 마지막 단계가 빠져있어 첫 사용자 경험 불완전
10. **게시물 작성 플로우 없음**: 커뮤니티 탭에서 글쓰기 버튼이 Alert만 표시

## 2. 유저 플로 정의

### Flow A: 첫 방문자 — 앱 설치부터 첫 루틴 구매까지

```
[앱 실행]
  │
  ▼
SPLASH (2초, 로고 + 민트 배경)
  │
  ▼
WALKTHROUGH
  ├── Slide 1: "전문가가 만든 루틴으로 시작하세요"
  ├── Slide 2: "매일 체크하며 나를 바꿔보세요"
  └── Slide 3: "함께하면 더 재미있어요" → [시작하기] 버튼
  │
  ▼
LOGIN 화면
  ├── [카카오 로그인] → 데모 로그인 처리 (OAuth 미구현, P1)
  ├── [애플 로그인] → 데모 로그인 처리 (OAuth 미구현, P1)
  ├── [구글 로그인] → 데모 로그인 처리 (OAuth 미구현, P1)
  └── [이메일로 시작하기] → SIGNUP 화면
        ├── 이메일 입력 (형식 검증)
        ├── 비밀번호 입력 (8자 이상)
        ├── 비밀번호 확인 (일치 검증)
        ├── 닉네임 입력 (2~12자)
        └── [가입하기] → 약관 동의(ONBOARD-07)는 MVP에서 가입 폼에 체크박스로 통합
  │
  ▼
PREFERENCE 화면
  ├── "어떤 루틴에 관심이 있나요?"
  ├── 카테고리 칩 다중 선택: 💪운동 / 🥗식단 / 🎓자기계발 / 📝자격증 / 📚학업
  ├── 최소 1개 선택 필수 (미선택 시 [완료] 버튼 비활성)
  └── [완료] → authStore.setPreferences() + setOnboarded()
  │
  ▼
HOME (루틴 스토어)
  ├── 선택한 카테고리 기반으로 추천 루틴 상단 노출
  ├── 루틴 카드 탭 → ROUTINE DETAIL
  │
  ▼
ROUTINE DETAIL (/routine/[id])
  ├── 루틴 정보 확인 (Provider, 설명, 일별 미리보기)
  ├── 기간 선택 (1주 / 4주 / 100일)
  └── [구매하기] 버튼
  │
  ▼
PURCHASE (/purchase/[id]) — 모달
  ├── 주문 요약 (루틴명, Provider, 기간, 금액)
  ├── 결제 수단 선택 (카드 / 카카오페이 / 네이버페이 / 토스)
  ├── 이용약관 동의 체크
  └── [결제하기] → 1.5초 로딩 → 결제 완료
  │
  ▼
결제 완료 화면 (Alert 또는 화면)
  ├── "결제가 완료되었습니다!" + 루틴명 + 금액
  ├── [일정 설정하기] → SCHEDULE SELECT (시작일 선택)
  └── [나중에 설정할게요] → HOME
  │
  ▼
(일정 설정 선택 시)
BOARD 탭으로 이동 → 구매한 루틴이 보드에 자동 추가됨
  ├── 오늘 날짜의 투두 아이템 표시
  └── 체크박스 토글로 완료 처리
```

### Flow B: 기존 사용자 — 매일 루틴 실행

```
[앱 실행] → isAuthenticated + isOnboarded → BOARD 탭 직행
  │
  ▼
BOARD 탭 (하단 네비게이션) — 기존 사용자의 기본 랜딩
  ├── 오늘 요일 자동 선택 (하이라이트)
  ├── 진행 중인 루틴 카드들 표시
  │   ├── 카드 탭 → 확장 (투두 리스트 펼침)
  │   ├── 체크박스 탭 → 완료 토글
  │   └── D-Day 카운터 표시
  ├── 요일 탭 → 해당 요일의 투두로 필터링
  └── [HOW TO BE 추가하기] FAB → HOME (새 루틴 탐색)
```

### Flow C: 커뮤니티 참여

```
POST 탭 (하단 네비게이션)
  │
  ▼
커뮤니티 피드
  ├── 카테고리 탭 전환 (전체/후기/일상/질문/꿀팁)
  ├── 게시물 카드
  │   ├── ❤️ 좋아요 탭 → 토글 (카운트 ±1)
  │   ├── 💬 댓글 아이콘 탭 → 게시물 상세 (MVP 이후)
  │   └── 🔖 북마크 탭 → 저장 토글
  └── ✍️ 글쓰기 아이콘 → 게시물 작성 (MVP 이후)
```

### Flow D: MY 페이지 관리

```
MY 탭 (하단 네비게이션)
  │
  ▼
MY 프로필 메인
  ├── [프로필 편집] → /my/edit-profile
  │   ├── 사진 변경
  │   ├── 닉네임/소개 수정
  │   └── [저장] → 프로필 업데이트
  ├── 팔로워 숫자 탭 → /my/followers?tab=followers
  ├── 팔로잉 숫자 탭 → /my/followers?tab=following
  ├── [내 루틴] → /my/routines
  │   ├── 진행중 탭 → 활성 루틴 리스트 (진행률 바)
  │   └── 완료 탭 → 완료된 루틴 리스트
  ├── [구매 내역] → /my/purchase-history
  │   └── 구매 리스트 (날짜, 루틴명, 금액, 상태)
  ├── [QR 코드] → /my/qr-center (MVP 이후)
  ├── [설정] → /my/settings
  │   ├── [알림 설정] → /my/notifications
  │   │   └── 토글 3개 (일정/커뮤니티/마케팅)
  │   ├── [로그아웃] → 확인 Alert → 로그아웃 → Splash
  │   └── [회원탈퇴] → 확인 Alert → 탈퇴 → Splash
  └── [고객센터] → 외부 링크 또는 안내 화면
```

## 4. 화면별 인터랙션 명세

### 4-1. SPLASH

```
화면 ID: AUTH-SPLASH
라우트: /(auth)/splash
```

| 요소 | 동작 | 조건 |
|------|------|------|
| 화면 진입 | 2초 타이머 시작 | 항상 |
| 2초 후 | `router.replace('/walkthrough')` | `!isAuthenticated` |
| 2초 후 | `router.replace('/(tabs)/board')` | `isAuthenticated && isOnboarded` |
| 2초 후 | `router.replace('/preference')` | `isAuthenticated && !isOnboarded` |

**UI 구성:**
- 전체 화면 민트(`#2dd4a8`) 배경
- 중앙: HTB 로고 (텍스트 "HOW TO BE")
- 하단: 로딩 인디케이터 (ActivityIndicator)

---

### 4-2. WALKTHROUGH

```
화면 ID: AUTH-WALKTHROUGH
라우트: /(auth)/walkthrough
```

| 요소 | 동작 |
|------|------|
| 스와이프 좌 | 다음 슬라이드 |
| 스와이프 우 | 이전 슬라이드 |
| [건너뛰기] (우상단) | `router.replace('/login')` |

## 7. 개발 시 주의사항

### 스토어 간 연결 규칙

```
authStore
  └── login/signup 성공 → isAuthenticated = true
  └── setPreferences → preferences 저장
  └── setOnboarded → isOnboarded = true (Preference 완료 후)
  └── logout → 모든 스토어 초기화

routineStore
  └── 루틴 목록 제공 (HOME 화면)
  └── getRoutineById → 루틴 상세 데이터

purchaseStore
  └── setRoutine + setPeriod → 결제 준비
  └── processPurchase 성공 → userStore.myRoutines에 추가 (현재 미연결 — 보강 필요)

userStore
  └── 프로필 + 내 루틴 + 팔로워/팔로잉 데이터
  └── myRoutines → BOARD 화면에서 사용 (현재 하드코딩 — 보강 필요)
```

### 파일 네이밍 규칙

- 컴포넌트 파일: `PascalCase.tsx` (예: `RoutineCard.tsx`)
- 스토어 파일: `camelCase.ts` (예: `authStore.ts`)
- 유틸/훅: `camelCase.ts` (예: `format.ts`, `useAuth.ts`)
- 라우트 파일: `kebab-case.tsx` (예: `edit-profile.tsx`)

### 디자인 토큰 참조

모든 색상/타이포/스페이싱은 `mobile/src/theme/tokens.ts` 참조:
- 색상: `colors.primary`, `colors.text.primary` 등
- 폰트: `typography.h1`, `typography.body1` 등
- 간격: `spacing.md` (16px), `spacing.lg` (24px) 등
